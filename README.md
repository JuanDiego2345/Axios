## Convención de Ramas y Commits

Para mantener un historial limpio y estructurado en el repositorio, seguimos la siguiente convención para el nombrado de ramas y mensajes de commit.

---

### Nombramiento de Ramas

Las ramas deben llevar la estructura `tipo/componente-descripcion`:

* **Estructura base:** `<tipo>/<módulo>-<funcionalidad>`
* **Tipos comunes:** `feature/`, `fix/`, `refactor/`

#### Ejemplos de Ramas:
```text
feature/analizador-lexico
feature/analizador-sintactico
feature/generador-kethari
feature/generador-oz
fix/normalizador-caracteres-especiales
